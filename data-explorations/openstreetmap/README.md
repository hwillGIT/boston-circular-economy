## OpenStreetMap (OSM)
OpenStreetMap is a collaborative project to create a free editable map of the world. The data from OSM is used in various applications, including navigation, geocoding, and geographic information systems (GIS).

## Overpass API
https://wiki.openstreetmap.org/wiki/Overpass_API

## Terms used in this document

- **OpenStreetMap (OSM)** — a collaboratively maintained, freely editable world map used here as a data source for circular-economy locations.
- **Overpass API** — a read-only query API for retrieving OSM data by tags, bounding box, or other criteria; used to fetch candidate locations without editing the map.
- **data source** — an external provider of location data that the ETL pipeline fetches records from. OSM is one data source; Google Places is another.
