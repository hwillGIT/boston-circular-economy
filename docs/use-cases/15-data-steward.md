## Source

Proposed. Follows from the reviewed catalog file and the Withdrawn list. Team docs: "avoid personal knowledge silos" and "minimal maintenance".

## Why this rank

Everything a resident sees comes from the catalog. If no one keeps it true, the app fails. Volunteers leave, so the task must be small and written down.

## Goals

- Add, fix and withdraw rows
- Re-check old rows on a schedule
- Hand over to the next volunteer

## Main journey

1. **Start.** Opens the monthly check list.
2. **Check.** Calls or reads the source.
3. **Edit.** Changes a row. Adds source and date.
4. **Test.** Build check passes.
5. **Hand off.** Notes the change for the next steward.

## Edge cases

- A row has no proof: it moves to Unconfirmed, with no map pin.
- Two stewards edit the same row: review catches it.
- Steward leaves: a written runbook covers the steps.

## Success measure

A new steward does a full monthly check from the runbook alone, in under 2 hours.
