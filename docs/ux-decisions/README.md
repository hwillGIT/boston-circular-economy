# UX Design Decision Records (UXDR)

This directory contains records of UX/UI decisions made for the Boston Circular Economy project.

- [UXDR-002: Activity Logging Flow](./UXDR-002-activity-logging-flow.md) - Adopt Strava/Olio ultra-low friction pattern — 2 required fields, <15 seconds
- [UXDR-003: Trust & Social Proof](./UXDR-003-trust-social-proof.md) - Adopt 3-tier trust badge system + social proof counters
- [UXDR-004: Impact Visualization](./UXDR-004-impact-visualization.md) - Tangible CO₂ equivalencies + weekly progress + streak tracking
- [UXDR-005: Card Design Hierarchy](./UXDR-005-card-design-hierarchy.md) - Google Maps / Yelp card hierarchy with quick action row
- [UXDR-006: Empty States & Loading](./UXDR-006-empty-states-loading.md) - Friendly conversational empty states with recovery actions + skeleton shimmer loading
