## Status Definitions

- **DRAFT**: Spec is being written.
- **IN REVIEW**: Spec is waiting for approval from stakeholders.
- **APPROVED**: Spec is approved and ready for implementation.
- **IN PROGRESS**: Development work has started.
- **IMPLEMENTED**: Code is merged but not fully verified in production.
- **VERIFIED**: Feature is live and working as expected.

## Priority Definitions (MoSCoW)

- **MUST**: Critical to the success of the project.
- **SHOULD**: Important but not strictly necessary for MVP.
- **COULD**: Nice to have, will be included if time permits.
- **WON'T**: Explicitly excluded from the current scope.
