# Interested collaborators

This directory provides public professional contact routes for people connected
to _No Waste to Spare: An Economic and Spatial Analysis of Massachusetts'
Reuse Economy_. The [project record][project-record] identifies it as a 2021
Tufts University Urban and Environmental Policy and Planning field project for
MassDEP. It does not identify the work as a UMass project.

Use these routes for project-related outreach. Verify a role and email address
before sending a message because organizations and roles can change. The
directory excludes personal addresses, private phone numbers, and inferred
email addresses.

use the relevant organization contact page instead of guessing an address.
